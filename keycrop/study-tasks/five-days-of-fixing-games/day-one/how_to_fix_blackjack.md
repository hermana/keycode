# How to fix the Blackjack game

To fix the game, you will need to make the following edits to the file. 

1. The print function is misspelled as `prisnt` throughout the file. You can use `CTRL+H` or `CMD+H` to correct the spelling.

2. Lines 127 to 138 should be indented such that they are within the `while` loop. You can highlight lines 127 to 138 use `CTRL+]` or `CMD+]` to indent them so that they are within the loop. 

3. Click within the brackets of the the `getBet()` function call on line 45 and use `CTRL+SHIFT+SPACE` or `CMD+SHIFT+SPACE` to check which parameter is missing from the function call. Once you have added it, the program should run without errors.
