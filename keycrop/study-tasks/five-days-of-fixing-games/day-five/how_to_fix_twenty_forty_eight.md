# How to fix the Twenty Forty Eight game

To fix the game, you will need to make the following edits to the file. 

1. The variable `board` is sometimes misspelled as `bloard` in the file. You can use `CTRL+H` (Windows/Linux) or `CMD+H` (Mac) to correct the spelling so that it is consistent.

2. Lines 181 to 199 should be indented such that they are within the `for` loop. You can highlight lines 181 to 199 use `CTRL+]` (Windows/Linux) or `CMD+]` (Mac) to indent them so that they are within the loop. 

3. Click within the brackets of the `combineTilesInColumn()` function call on line 194 use `CTRL+SHIFT+SPACE` (Windows/Linux) or `CMD+SHIFT+SPACE` (Mac) to check which parameter is missing from the function call. Once you have added it, the program should run without errors.
