# How to fix the Twenty Forty Eight game

To fix the game, you will need to make the following edits to the file. 

1. The variable `board` is sometimes misspelled as `bloard` in the file. You can use `CTRL+H` or `CMD+H` to correct the spelling so that it is consistent.

2. Lines 181 to 199 should be indented such that they are within the `for` loop. You can highlight lines 181 to 199 use `CTRL+]` or `CMD+]` to indent them so that they are within the loop. 

3. Click within the brackets of the the `combineTilesInColumn()` function call on line 194 use `CTRL+SHIFT+SPACE` or `CMD+SHIFT+SPACE` to check which parameter is missing from the function call. Once you have added it, the program should run without errors.


# Running the game

1. Open your terminal (`` CTRL+` `` or `` CMD+` ``) and `cd` into the same directory as `twenty_forty_eight.py`. 
2. Run `python twenty_forty_eight.py`. 
3. You have completed the task!
