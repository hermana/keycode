# How to fix the Tower of Hanoi game

To fix the game, you will need to make the following edits to the file. 

1. The function `if` is misspelled as `iff` in the file. You can use `CTRL+H` or `CMD+H` to correct the spelling.

2. Lines 51 to 79 should be indented such that they are within the `while` loop. You can highlight lines 51 to 79 use `CTRL+]` or `CMD+]` to indent them so that they are within the loop. 

3. Click within the brackets of the the `displayTowers()` function call on line 41 use `CTRL+SHIFT+SPACE` or `CMD+SHIFT+SPACE` to check which parameter is missing from the function call. Once you have added it, the program should run without errors.


# Running the game

1. Open your terminal (`` CTRL+` `` or `` CMD+` ``) and `cd` into the same directory as `tower_of_hanoi.py`.
