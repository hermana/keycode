# How to fix the Four in a Row game

To fix the game, you will need to make the following edits to the file. 

1. The keyword `return` is sometimes misspelled as `retune` in the file. You can use `CTRL+H` or `CMD+H` to correct the spelling.

2. Lines 157 to 171 should be indented such that they are within the `for` loop. You can highlight lines 157 to 171  use `CTRL+]` or `CMD+]` to indent them so that they are within the loop. 

3. Click within the brackets of the the `isWinner()` function call on line 38 use `CTRL+SHIFT+SPACE` or `CMD+SHIFT+SPACE` to check which parameter is missing from the function call. Once you have added it, the program should run without errors.


# Running the game

1. Open your terminal (`` CTRL+` `` or `` CMD+` ``) and `cd` into the same directory as `four_in_a_row.py`. 
2. Run `python four_in_a_row.py`. 
3. You have completed the task!
