# How to fix the Hungry Robots game

To fix the game, you will need to make the following edits to the file. 

1. The parameter `board` is sometimes misspelled as `bloard` throughout the file. You can use `CTRL+H` or `CMD+H` to replace all occurences where the spelling is not consistent.

2. Lines 45 to 60 should be indented such that they are within the `while` loop. You can highlight lines 45 to 60  use `CTRL+]` or `CMD+]` to indent them so that they are within the loop. 

3. Click within the brackets of the the `moveRobots()` function call on line 54 use `CTRL+SHIFT+SPACE` or `CMD+SHIFT+SPACE` to check which parameter is missing from the function call. Once you have added it, the program should run without errors.


# Running the game

1. Open your terminal (`` CTRL+` `` or `` CMD+` ``) and `cd` into the same directory as `hungry_robots.py`. 
2. Run `python hungry_robots.py`. 
3. You have completed the task!
