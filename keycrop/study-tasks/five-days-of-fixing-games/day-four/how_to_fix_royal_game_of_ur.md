# How to fix the Royal Game of Ur game

To fix the game, you will need to make the following edits to the file. 

1. The keyword `True` is sometimes misspelled as `true` in the file. You can use `CTRL+H` or `CMD+H` to correct the spelling.

2. Lines 233 to 254 should be indented such that they are within the `for` loop. You can highlight lines 233 to 254 use `CTRL+]` or `CMD+]` to indent them so that they are within the loop. 

3. Click within the brackets of the the `getValidMoves()` function call on line 122 use `CTRL+SHIFT+SPACE` or `CMD+SHIFT+SPACE` to check which parameter is missing from the function call. Once you have added it, the program should run without errors.


# Running the game

1. Open your terminal (`` CTRL+` `` or `` CMD+` ``) and `cd` into the same directory as `royal_game_of_ur.py`. 
2. Run `python royal_game_of_ur.py`. 
3. You have completed the task!
