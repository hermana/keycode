# Day One: Countries


In this activity, you will be asked to record some information about an arbitrary country of your choice. You will replace the contents of this file with the country's information. 

1. To begin, take a look at this file in Markdown's preview mode. You can open the preview in the current tab with `Ctrl+Shift+V` (Windows/Linux) or `Cmd+Shift+V` (Mac), or open it side by side with the editor using `Ctrl+K V` (Windows/Linux) or `Cmd+K V` (Mac). You may want to intermittently check how the file displays in preview mode as you work. 

2. You will need to refer to the instructions in this file to complete the task, however, the instructions should not appear in the final version of the file. Comment out the instructions as a block by highlighting all contents of the file and using `Ctrl+Shift+A` (Windows/Linux) or `Cmd+Shift+A` (Mac).

3. Choose any arbitrary country. 

4. Add 5 headings to the file. Initially, the text of the headings will be identical. You can type all 5 headings at once using multicursor. Use Add Cursor Below (`Ctrl+Shift+Down` / `Cmd+Shift+Down`) to get 5 sequential cursors, then type the heading: `# <COUNTRY_NAME>`. 

5. Add subheadings. Use either  Add Cursor Below (`Ctrl+Shift+Down` / `Cmd+Shift+Down`) or Add Cursor Above (`Ctrl+Shift+Up` / `Cmd+Shift+Up`) to insert a cursor after the `#` in all the headers except for the first one. Add a second `#` to make them subheadings, then move the cursor to the end of the country name and add a `:`. 

6. You can now look up four qualities of that country and add them to the headers.
